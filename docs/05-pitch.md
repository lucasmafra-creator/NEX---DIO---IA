# Pitch — roteiro de até 3 minutos

## 0:00–0:30 — Problema
Olá, meu nome é Lucas Mafra e este é o Nex, um assistente financeiro criado com Inteligência Artificial. Registrar gastos é relativamente simples; transformar esses números em informação realmente útil nem sempre é.

## 0:30–1:05 — Solução
O Nex conversa sobre uma base financeira fictícia e ajuda a compreender gastos, categorias, saldo e metas. Durante o projeto adotei um princípio: **a IA explica, o sistema calcula e os dados comprovam**. Valores críticos são calculados pelo sistema e, quando uma informação não existe, o Nex deve admitir a limitação em vez de inventar.

## 1:05–2:15 — Demonstração
Abra o aplicativo e mostre, **uma pergunta por vez**:
1. `Quanto gastei com alimentação?`
2. `Qual categoria teve maior gasto?`
3. `Quanto sobrou?`
4. `Como está minha reserva?`
5. `Quanto eu gastava com alimentação há um ano?`

Explique que a última pergunta solicita um período ausente. O Nex reconhece a falta de dados em vez de criar um número.

## 2:15–2:45 — Avaliação
O projeto possui testes automatizados para cálculos, contexto, segurança e ausência de dados. O objetivo não é criar uma IA que sempre responda qualquer coisa, mas uma IA capaz de reconhecer os limites da informação disponível.

## 2:45–3:00 — Encerramento
O Nex demonstra como Inteligência Artificial Generativa pode tornar dados financeiros mais fáceis de compreender, mantendo segurança e transparência. Esse é o Nex. Obrigado!
