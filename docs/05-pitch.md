# Pitch — roteiro rápido (1min30–2min)

## Script

**[0:00–0:20 | mostrar o Nex AI]**

Olá, meu nome é Lucas Mafra e este é o **Nex AI**, um assistente financeiro desenvolvido para o desafio da DIO. A proposta é transformar dados financeiros em informações simples e úteis para o usuário.

**[0:20–0:40 | mostrar a interface]**

O Nex utiliza uma base fictícia com transações, perfil e metas. Um princípio guiou o projeto: **a IA explica, o sistema calcula e os dados comprovam**. Assim, os valores financeiros são calculados pelo sistema e o assistente evita inventar informações.

**[0:40–1:20 | demonstração]**

Agora vou perguntar: **“Quanto gastei com alimentação?”**  
O Nex consulta a base e apresenta o valor calculado.

Depois: **“Quanto sobrou?”**  
Ele utiliza as entradas e saídas para apresentar o saldo.

Por último: **“Quanto eu gastava com alimentação há um ano?”**  
Esse período não existe na base. Em vez de inventar um número, o Nex informa que não possui dados suficientes.

**[1:20–1:40 | mostrar interface/README]**

Também implementei testes para validar cálculos, segurança, contexto e situações com dados ausentes.

**[1:40–1:55 | encerramento]**

O resultado é um protótipo funcional que demonstra como IA pode ajudar na compreensão financeira com mais clareza e segurança. Esse é o **Nex AI**. Obrigado!
