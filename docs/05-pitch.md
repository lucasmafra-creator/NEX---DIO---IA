## Script utilizado como base

**Problema e apresentação**

Olá, meu nome é Lucas Mafra e este é o **Nex AI**, um assistente financeiro desenvolvido para o desafio da DIO. A proposta é transformar dados financeiros em informações simples e úteis para o usuário.

**Solução**

O Nex utiliza uma base fictícia com transações, perfil e metas. Um princípio guiou o projeto: **a IA explica, o sistema calcula e os dados comprovam**. Assim, os valores financeiros são calculados pelo sistema e o assistente evita inventar informações.

**Demonstração**

O protótipo permite consultar gastos, saldo e outras informações financeiras. Também demonstra tratamento de dados ausentes: quando o usuário solicita informações de um período inexistente na base, o Nex informa que não possui dados suficientes em vez de inventar um número.

**Avaliação**

Foram implementados testes para validar cálculos, segurança, contexto e situações com dados ausentes.

**Encerramento**

O resultado é um protótipo funcional que demonstra como IA pode ajudar na compreensão financeira com mais clareza e segurança.

Esse é o **Nex AI**.
