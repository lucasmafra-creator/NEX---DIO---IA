# Base de Conhecimento

| Arquivo | Formato | Uso |
|---|---|---|
| `transacoes.csv` | CSV | Receitas, despesas e categorias |
| `historico_atendimento.csv` | CSV | Contexto fictício de atendimentos |
| `perfil_investidor.json` | JSON | Perfil, objetivo e metas |
| `produtos_financeiros.json` | JSON | Produtos fictícios para explicação |

Os dados são carregados localmente. Cálculos críticos são feitos em Python antes da resposta. Somente fatos relevantes são transformados em contexto para a camada de linguagem.

> **A IA explica. O sistema calcula. Os dados comprovam.**

Quando um período ou informação não existe na base, o agente deve declarar a limitação em vez de estimar um valor como fato.
